🎨 Asset di terze parti

Sprite Pokémon

Forniti da PokeAPI (community-maintained), tramite il repository PokeAPI/sprites.

Gli sprite originali derivano dai giochi Pokémon e sono proprietà di Nintendo / Game Freak / The Pokémon Company. PokeAPI li ridistribuisce a scopo informativo / API educativa.

Sprite Allenatori

Forniti da Pokémon Showdown (progetto community open-source).

Gli sprite originali derivano dai giochi Pokémon Gen 1-3 e sono proprietà di Nintendo / Game Freak / The Pokémon Company.

Audio / Sound Effects

Tutti gli SFX sono sintetizzati in tempo reale nel browser tramite Web Audio API (oscillatori + envelope). Nessun file audio binario distribuito.

Stile chiptune retro ispirato all'estetica audio degli 8-bit, ma composizioni e timbri originali del progetto.

Musiche di sottofondo

Tracce 8-bit utilizzate come musica di sottofondo (menu e battaglia segreta) sono rearrangement chiptune fan-made ispirate al materiale musicale dei giochi Pokémon. I diritti delle composizioni originali appartengono a Nintendo / Game Freak / The Pokémon Company.

In futuro le tracce verranno sostituite da brani Creative Commons da OpenGameArt.org, Free Music Archive o composizioni originali. Per ogni altro contesto le tracce sono generate proceduralmente in tempo reale (Web Audio API, composizioni originali del progetto).

Dati Pokémon (mosse, tipi, statistiche)

Forniti da PokeAPI. I bilanciamenti specifici di mosse e passive sono adattamenti originali per questo progetto.

Caratteri / Font

Font di sistema, nessun font esterno distribuito.

⚙ Tecnologie

  • HTML5 / CSS3 / JavaScript ES Modules (vanilla, zero framework)
  • Web Audio API per gli effetti sonori procedurali
  • Service Worker (PWA) per il funzionamento offline e l'installazione
  • Supabase (opzionale) per il salvataggio cloud cross-device
  • Pointer Events + Drag & Drop API per il touch su mobile
